# Experiment 12: Build Web App using Flutter

## Aim
To develop, run, and build a responsive Flutter application for the Web using Flutter and Chrome.

## Description
This experiment demonstrates how Flutter allows developers to create web applications using the same Flutter framework used for mobile applications. A responsive web application adapts between mobile and desktop web views.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_12_Web_Application
flutter pub get
flutter run
```
