# Experiment 8: Data Persistence using SQLite and Firebase

## Aim
To Implement data persistence in a Flutter application using SQLite for local storage and Firebase Cloud Firestore for cloud storage, to perform basic data operations such as insertion, retrieval, updating, and deletion.

## Description
This experiment demonstrates how Flutter applications can store data permanently using SQLite for local device storage and Firebase Cloud Firestore for cloud persistence.

## Files
- `lib/database_helper.dart`
- `lib/firebase_options.dart`
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_08_Data_Persistence_SQLite_Firebase
flutter pub get
flutter run
```
