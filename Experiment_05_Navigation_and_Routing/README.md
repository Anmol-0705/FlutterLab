# Experiment 5: Implementation of Navigation and Routing

## Aim
To implement navigation between multiple Flutter screens using Navigator and named routes.

## Description
This experiment demonstrates how to navigate between multiple screens in a Flutter application. The application contains Home, Profile, and Details screens. Named routes are used for forward navigation and Navigator.pop for backward navigation.

## Files
- `lib/main.dart`
- `lib/home.dart`
- `lib/profile.dart`
- `lib/details.dart`

## How to Run Locally
```bash
cd Experiment_05_Navigation_and_Routing
flutter pub get
flutter run
```
