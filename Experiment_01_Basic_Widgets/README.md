# Experiment 1: Basic Widgets and Layouts

## Aim
To develop a Flutter application using basic widgets and layout widgets such as Container, Row, Column, Expanded, Card, and ListView.

## Description
This experiment demonstrates the development of a Flutter student profile/dashboard application using basic widgets and layout widgets. The main concepts include MaterialApp, Scaffold, StatelessWidget, AppBar, Column, Row, Container, Icon, Card, ListTile, and ListView.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_01_Basic_Widgets
flutter pub get
flutter run
```
