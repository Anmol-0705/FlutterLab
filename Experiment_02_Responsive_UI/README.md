# Experiment 2: Adaptive and Responsive UI Design

## Aim
To create a Flutter application that automatically adapts its layout according to the available screen size.

## Description
This experiment demonstrates the development of a responsive Flutter application that automatically changes its user interface according to the screen width. The application uses LayoutBuilder to provide different layouts for mobile, tablet, and desktop-sized screens.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_02_Responsive_UI
flutter pub get
flutter run
```
