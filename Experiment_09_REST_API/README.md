# Experiment 9: Access REST API using HTTP

## Aim
To access a REST API using HTTP and retrieve and display JSON data in a Flutter application.

## Description
This experiment demonstrates how Flutter communicates with a REST API using the http package. The application sends a GET request to the JSONPlaceholder API, converts the JSON response into Dart data, and displays the posts using ListView.builder.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_09_REST_API
flutter pub get
flutter run
```
