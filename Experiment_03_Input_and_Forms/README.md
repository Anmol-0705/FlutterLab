# Experiment 3: Add Interactivity to App - Input and Forms

## Aim
To create an interactive Flutter student registration form with input fields and validation for Student Name, Email, and Password, along with a Submit button.

## Description
This experiment demonstrates how to add interactivity to a Flutter application using input fields and forms. A Form is used to group input fields, GlobalKey<FormState> validates inputs, and SnackBar provides user feedback.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_03_Input_and_Forms
flutter pub get
flutter run
```
