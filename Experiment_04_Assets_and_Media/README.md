# Experiment 4: Utilize Assets and Media

## Aim
To add and display image, audio and video assets in a Flutter application.

## Description
This experiment demonstrates how to add and display image, audio, and video assets in a Flutter application. Assets are stored in the assets folder, declared in pubspec.yaml, and rendered via Flutter widgets with interactive video controls.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_04_Assets_and_Media
flutter pub get
flutter run
```
