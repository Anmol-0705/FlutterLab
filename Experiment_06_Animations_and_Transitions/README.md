# Experiment 6: Integrate Animations and Transitions

## Aim
To Implement animations and smooth transitions in a Flutter application using AnimatedContainer.

## Description
This experiment demonstrates the use of Flutter's AnimatedContainer to create a smooth size transition. A button is provided to change the size of the widget dynamically using setState().

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_06_Animations_and_Transitions
flutter pub get
flutter run
```
