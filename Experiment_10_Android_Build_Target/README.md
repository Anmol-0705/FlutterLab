# Experiment 10: Configure and Build for Android

## Aim
To configure and build a Flutter application for the Android platform.

## Description
This experiment demonstrates how to configure Flutter for Android development, check connected Android devices, accept Android SDK licenses, run the application on an Android device or emulator, and generate an APK file.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_10_Android_Build_Target
flutter pub get
flutter run
```
