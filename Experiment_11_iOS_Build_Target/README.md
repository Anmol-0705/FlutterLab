# Experiment 11: Add iOS as a Build Target

## Aim
To create a Flutter application with an iOS build target, test the application, and deploy its Flutter Web version using GitHub Pages.

## Description
This experiment demonstrates how a Flutter application can be configured with iOS as a target platform, tested across targets, and deployed on GitHub Pages.

## Files
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_11_iOS_Build_Target
flutter pub get
flutter run
```
