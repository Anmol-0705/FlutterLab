# Experiment 7: Application State Management and Serialization

## Aim
To manage application state and serialize/deserialize data using JSON in a Flutter application.

## Description
This experiment demonstrates application state management using setState() and JSON serialization/deserialization using a Student model. Student data is converted from a Dart object into JSON format using toJson() and converted back into a Dart object using fromJson(). A list of students is displayed dynamically using ListView.builder().

## Files
- `lib/student.dart`
- `lib/main.dart`

## How to Run Locally
```bash
cd Experiment_07_State_Management_and_Serialization
flutter pub get
flutter run
```
